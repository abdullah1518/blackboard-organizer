# Antigravity Task Specification: Blackboard TaskSync & Calendar Exporter Extension

## 1. Project Overview & Boundaries
* **Artifact:** Google Chrome Extension (Manifest V3)
* **Tech Stack:** TypeScript, React (Vite-based build), TailwindCSS, WebExtension Polyfill, `ics` (or zero-dep RFC 5545 generator).
* **Target Platforms:** Blackboard Learn Ultra and Blackboard Learn Original.
* **Core Philosophy:** 100% Local-First. Zero remote telemetry, zero external backend databases. All state persists in `chrome.storage.local`.

## 3. Architecture & Functional Requirements

### 3.1 Extension Topology (Chrome Manifest V3)
* **Popup UI (`src/popup/index.html`):** Quick snapshot view of items due in the next 48 hours; quick-export button.
* **Side Panel UI (`src/sidepanel/index.html`):** Full-height task management workspace with search, course grouping, status filtering, custom tasks, and settings.
* **Content Script (`src/content/index.ts`):** Injected on matching domains (`*://*.blackboard.com/*` or customizable institutional URLs) to read DOM state, extract CSRF tokens, and detect active student sessions.
* **Background Service Worker (`src/background/index.ts`):** Orchestrates background fetching via authenticated session endpoints, updates Chrome badge text (showing pending items due <24h), and handles scheduled alarms.
* **Local Storage (`chrome.storage.local`):** 100% local-first cache storing tasks, course mapping, completion flags, and user preferences. Zero remote telemetry.

### 3.2 Data Extraction & Ingestion Engine
* **FR-1.1 Multi-Mode Extraction:**
  * **Primary (Ultra REST API):** Query Blackboard internal session endpoints (`/learn/api/public/v1/calendars/items`, `/webapps/calendar/calendarData/`) using active browser session.
  * **Secondary (Calendar Feed Ingestion):** Parse student's personal Blackboard calendar subscription link (`webcal://` or ical feed endpoint).
  * **Tertiary (DOM Scraping Fallback):** Fallback content script to scrape Activity Stream (`/ultra/stream`) or Gradebook/Calendar page DOM for assignments, tests, and dates.
* **FR-1.2 Item Classification:**
  * `ASSIGNMENT` (Submissions, projects, essays)
  * `QUIZ_TEST` (Timed tests, quizzes, midterms)
  * `DISCUSSION` (Graded discussion forum deadlines)
  * `CUSTOM_TASK` (User-created checklist items)
* **FR-1.3 Data Normalization Schema:**
  ```json
  {
    "id": "bb_item_982341",
    "courseId": "CS301_FALL26",
    "courseName": "Operating Systems",
    "title": "Lab 3: Virtual Memory",
    "type": "ASSIGNMENT",
    "dueDate": "2026-10-15T23:59:00Z",
    "url": "https://school.blackboard.com/ultra/courses/_1234/...",
    "isCompleted": false,
    "source": "BLACKBOARD",
    "lastSynced": "2026-10-01T12:00:00Z"
  }
  ```
* **FR-1.4 Deduplication:** Maintain unique identifiers across syncs to preserve user completion status and personal notes.

### 3.3 Task Management
* **FR-2.1 Task Views:** By Urgency (Overdue, Due Today, Due This Week, Later) and By Course.
* **FR-2.2 Status Tracking:** Checkbox toggle to mark tasks "Completed" / "Pending" with collapsible completed section.
* **FR-2.3 Custom Task Additions:** Create personal tasks linked to existing courses.
* **FR-2.4 Direct Navigation:** One-click navigation to Blackboard submission link in a new Chrome tab.
* **FR-2.5 Chrome Action Badge:** Red badge counter on the extension icon showing incomplete items due within the next 24 hours.

### 3.4 Calendar File Generation & Export Engine
* **FR-3.1 RFC 5545 Compliance:** Standards-compliant `.ics` format for Google Calendar, Apple Calendar, Outlook.
* **FR-3.2 Export Customization:** Scope selection (all vs. pending, course selection), item type filters, customizable reminders (`VALARM`: 24h, 2h), unified vs. per-course `.ics` files.
* **FR-3.3 Event Metadata:** Formatted summaries `[Course Code] Title`, proper UTC start/end timestamps, deep-links, and stable UIDs.
